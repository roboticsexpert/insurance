# یادداشت جلسه — بیمه تعاون، ۱۲ شهریور ۱۴۰۵ (۲۰۲۶-۰۹-۰۳)

نخستین جلسه اطلاعات‌گیری با **بیمه تعاون** درباره وصل کردن پلتفرم ما به یک شرکت بیمه واقعی. از روی
یادداشت‌های همان جلسه نوشته شده؛ هرچه پایین آمده **آن چیزی است که گفته شد**، نه آنچه راستی‌آزمایی
شده باشد. درجه اطمینان برای هر ادعا جداگانه مشخص شده است.

مرتبط: [`docs/platform/CARRIER-INTEGRATION.md`](../platform/CARRIER-INTEGRATION.md) — سند طراحی
زنده‌ای که این جلسه به آن خوراک می‌دهد؛ [`docs/PLAN.md`](../PLAN.md) — برنامه ورود به بازار که
بخشی از پرسش‌های فاز ۰ آن اینجا جواب می‌گیرد.

---

## ۱. تیتر اصلی

**همه‌چیز روی هسته فناوران کار می‌کند.** سامانه صدور بیمه تعاون **فناوران اطلاعات خبره / IranEIT**
است (هسته «بنیان»). یک سطح دوم و کوچک‌تر هم برای **استعلام‌های بیمه مرکزی (سنهاب)** وجود دارد.
پس اتصالی که برای ما مهم است *واقعاً* «اتصال به تعاون» نیست — اتصال به **API فناوران** است، با
تعاون به‌عنوان مستأجری که ما را مجاز می‌کند.

این با پرسش بازی که همین حالا در پژوهش نشسته جور درمی‌آید و جوابش می‌دهد
(`core-insurance-va-sanhab.md`: «آیا هسته فناوران API خارجی مستند دارد یا هر اتصال برای هر شرکت
سفارشی است؟»). پاسخ، آن‌طور که گزارش شد: **فناوران API منیجر خودش را دارد**؛ دسترسی برای هر
مصرف‌کننده وقتی باز می‌شود که شرکت بیمه درخواستش را بدهد.

## ۲. ادعاهای مطرح‌شده در جلسه

| # | ادعا | درجه اطمینان طبق گفته |
|---|---|---|
| ۱ | بیمه تعاون **آنلاین** صادر می‌کند و API دارد؛ با ورودی‌های تمیز، بیمه‌نامه آنلاین صادر می‌شود | گفته خودشان، از سوی ما راستی‌آزمایی نشده |
| ۲ | تعاون **دو API** در اختیار می‌گذارد: **استعلام نرخ** و **درخواست صدور** | گفته شد |
| ۳ | مستندات API فناوران **هست ولی قابل استناد نیست** — مشخصات واقعی، دانش سینه‌به‌سینه است | گفته شد، با تأکید |
| ۴ | راه درست انجامش این است که **از کسی بپرسید که قبلاً پیاده‌اش کرده** | توصیه خودشان |
| ۵ | سابقه و تخفیف عدم‌خسارت (مثلاً «۳ سال بدون خسارت») باید از **API سوابق بیمه‌ای سنهاب** بیاید، نه از شرکت بیمه | گفته شد؛ نیاز به اعتبارسنجی دارد |
| ۶ | برای گرفتن هیچ‌کدام از این‌ها باید **کارگزار رسمی بیمه** باشید — پروانه همان چیزی است که اعتبارنامه سنهاب را باز می‌کند | گفته شد |
| ۷ | جایگزین مسیر پروانه‌محور: رابطه‌ای با **بیمه مرکزی** که نام کاربری/رمز سنهاب بدهد | گفته شد، مبهم |
| ۸ | فناوران API‌هایش را به شما باز می‌کند **به شرط اینکه کارگزاری و نماینده فروش داشته باشید** | گفته شد |
| ۹ | **۷۰۸۰** مستقیم سراغ فناوران رفت به‌عنوان یک شخصیت حقوقی شناخته‌شده در صنعت؛ بعد تعاون به فناوران گفت «دسترسی را باز کنید» و باز کردند | به‌عنوان سابقه گفته شد |
| ۱۰ | چند **سرویس استعلام** پیش‌نیازند نه اضافه: استعلام کد پستی، اسکان و مانند آن. سنهاب بیمه‌نامه‌ای که کد پستی‌اش ثبت نشده باشد را رد می‌کند | گفته شد |
| ۱۱ | هسته فناوران را بالا می‌داند: حدود ۲۵ سال، حدود ۲۵ شرکت بیمه | نظر شخصی |
| ۱۲ | **کوثر** و **پارسیان** (درباره پارسیان مطمئن نبود) به **فناپ** رفتند و برگشتند | شنیده — به‌عنوان واقعیت نقل نکنید |
| ۱۳ | در **بیمه معلم** برای رشته درمان از هسته دیگری استفاده می‌شد. اداره **همزمان دو هسته دردسر بزرگی است** — هر داشبورد باید از دو جا داده بکشد | تجربه، و یک هشدار |

## ۳. نام‌های بازار/تأمین‌کننده برای پیگیری

- **ازکی** — از راه کارگزار «کارگزار نوین» می‌فروشد (طبق گفته).
- **بیمه دات کام (bimeh.com)** — ساخته **رایکا** (هماهنگ با پژوهش خودمان که دارنده پروانه‌اش را
  «کارگزاری رسمی بیمه مستقیم برخط آریا پرداز رایکا» ثبت کرده است).
- **۷۰۸۰** — سابقه رفتن مستقیم سراغ فناوران.
- **فناپ** — هسته‌ای که می‌گویند امتحان کردند و رهایش کردند.

## ۴. چیزی که خواست پیش از جلسه بعد انجام دهیم

> «یه دور حتماً قبل از جلسه‌ی بعدی چرخیدم [در] سرویس تعاون» — یعنی جریان فروش آنلاین خود بیمه
> تعاون را سرتاسر طی کنید و ببینید واقعاً چطور رفتار می‌کند.

## ۵. این چه چیزی را برای ما عوض می‌کند

۱. **مرجع قیمت‌گذاری شرکت بیمه است، نه ما.** ماژول `rating` ما (سه محصول با جدول‌های نرخ محلی)
   روزی که با یک شرکت بیمه واقعی بالا برویم دیگر منبع حقیقت نیست؛ تبدیل به برآورد/جایگزین می‌شود.
   این یک مرز معماری صریح می‌خواهد — سند اتصال به شرکت بیمه را ببینید.
۲. **پروانه روی مسیر بحرانی است** و *هم* سنهاب و *هم* فناوران را قفل کرده. هیچ‌چیزی درباره دسترسی
   API پیش از آن تمام نمی‌شود.
۳. **سرویس‌های استعلام یک جریان کاری مستقل‌اند** (کد پستی، اسکان، سوابق سنهاب) و الزامات دسترسی
   خودشان را دارند.
۴. **به مستندات نمی‌شود اعتماد کرد** — برای یک فاز کشف/مهندسی معکوس و برای پیدا کردن کسی که اتصال
   فناوران را عملیاتی کرده بودجه بگذارید.

## ۶. پرسش‌ها برای جلسه بعد

طوری مرتب شده که گران‌ترین‌ها اول پرسیده شوند.

۱. آیا می‌توانیم **مشخصات واقعی API** آن دو سرویس (استعلام نرخ، درخواست صدور) به‌علاوه یک
   **محیط سندباکس/UAT** و اعتبارنامه تست را — پیش از رسیدن پروانه — داشته باشیم؟
۲. دسترسی از نظر فنی **از راه تعاون** است یا **از راه API منیجر فناوران**؟ اعتبارنامه را چه کسی
   صادر می‌کند، محدودیت نرخ دست کیست، و وقتی خراب شد چه کسی پاسخ‌گوست؟
۳. کدام **رشته‌ها** امروز واقعاً از راه API آنلاین صادر می‌شوند (شخص ثالث؟ مسافرتی؟ آتش‌سوزی منزل؟)
   و کدام هنوز یک آدم در تعاون می‌خواهند؟
۴. برای مسیر API: آیا **پروانه کارگزاری + نماینده فروش** پیش‌نیاز سخت است، یا می‌شود اول در
   سندباکس وصل شد و در زمان گرفتن پروانه محیط عملیاتی را روشن کرد؟
۵. **صدور** دقیقاً چه چیزی برمی‌گرداند — کد یکتای سنهاب، PDF، هر دو؟ همگام است یا صف‌شده؟
۶. **حالت‌های خطا**: وقتی سنهاب پایین است چه می‌شود، وقتی کد پستی ثبت نشده، وقتی استعلام با ادعای
   مشتری نمی‌خواند؟ آیا صدور idempotent است — کلید idempotency سمت کلاینت می‌شود فرستاد؟
۷. **کارمزد**: نرخ هر رشته، چه کسی ثبتش می‌کند، کی پرداخت می‌شود.
۸. کدام‌یک از **سرویس‌های استعلام** را تعاون/فناوران خودشان به ما می‌دهند و کدام را باید خودمان
   تهیه کنیم (کد پستی، اسکان، کد ملی/شاهکار، سابقه پلاک)؟
۹. **طرف فنی** ما در تعاون/فناوران چه کسی است، و می‌شود ما را به کسی که قبلاً روی این هسته پیاده‌سازی
   کرده معرفی کنند؟
۱۰. نرخ‌ها: آیا **جدول‌های نرخ** به‌صورت داده تحویل‌دادنی‌اند (اشاره‌اش به «با اکسل نمی‌شود» — ما
    باور داریم جدولی وجود دارد و می‌خواهیم ببینیمش)، یا هر قیمت یک فراخوانی API است؟

## ۷. پیگیری‌هایی که بر عهده ماست

- [ ] جریان خرید آنلاین تعاون را طی کنید و درخواست‌هایی که فرانت‌اند خودشان می‌زند را ثبت کنید.
- [ ] طراحی اتصال به شرکت بیمه (توپولوژی الف در برابر ب) را بنویسید — انجام شد، سند پلتفرم را ببینید.
- [ ] مسیر پروانه را تعیین کنید: مشارکت با کارگزار موجود یا درخواست مستقل.
- [ ] پژوهش منتشرشده را تازه کنید: پرسش باز `core-insurance-va-sanhab.md` درباره API خارجی فناوران
      حالا تا حدی با ادعاهای ۳، ۸ و ۹ بالا جواب گرفته است.
